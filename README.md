# Sankalp — Purohit Booking

A single-page ceremony booking site for Sankalp, built around a 3D-animated
scene of Shiva meditating underwater. Includes nine bookable Hindu ceremonies
across four categories, a live "Sankalpa Card" preview, and a front-end-only
booking confirmation flow.

Open `index.html` directly in a browser — everything (video, fonts) is
embedded as base64 data URIs, so no build step or server is required.

To preview via GitHub Pages, enable Pages for this repo (Settings → Pages →
Deploy from branch → `main` / root) and it will serve at
`https://<user>.github.io/sankalp-poojas/`.
